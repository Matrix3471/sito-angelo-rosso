## 1. Concept Generale

**"La risposta diretta di chi ti conosce già."**

Il design comunica una cosa sola: c'è una persona reale, vicina, che risponde subito. Non un ambulatorio, non una struttura, non un form che va in un database. Un numero di telefono, un WhatsApp, una voce che conosci. Ogni decisione grafica — dalla gerarchia tipografica ai colori, dalla posizione dei bottoni alle parole — serve a trasformare un visitatore ansioso (anziano, figlio caregiver, familiare che cerca soluzioni rapide) in qualcuno che preme "Scrivi su WhatsApp" entro 30 secondi dall'apertura della pagina.

## 3. Hero Section

### Struttura layout (desktop: 60/40 — copy a sinistra, elemento visivo a destra)

**HEADLINE (H1):**
```
ECG e Holter a domicilio
a Francofonte, Lentini e Carlentini
```
*Motivazione: la geo-localizzazione in H1 è il primo segnale SEO locale e il primo filtro di rilevanza per l'utente. Chi è di Lentini legge "Lentini" e smette di cercare altrove.*

**SOTTOTITOLO (H2 / lead):**
```
Il cardiologo ti ha chiesto un esame?
Vengo a casa tua. Senza lista d'attesa, senza spostamenti.
```
*Motivazione: parte dal bisogno reale dell'utente (la prescrizione del cardiologo), non dal servizio. La domanda retorica crea riconoscimento immediato — "sì, è esattamente la mia situazione".*

**CTA PRIMARIA — bottone principale:**
```
[ Scrivi su WhatsApp — rispondo io ]
```
Colore: `var(--accent)` #ff7a18, testo bianco, border-radius 8px, padding 16px 28px, font-weight 700, font-size 1.125rem. Icona WhatsApp SVG inline a sinistra del testo.

**CTA SECONDARIA — link testuale sotto:**
```
Oppure chiama il 331 567 7922
```
Colore: `var(--accent2)` #24c7b9, underline, font-weight 600. Non bottone — link pulito per non competere visivamente con la CTA primaria.

**BADGE TRUST (sotto le CTA, in riga orizzontale):**
```
✓ Iscritto OPI Siracusa   ✓ Referto PDF in 24–48h   ✓ Tariffe confermate al primo contatto
```
Font-size 0.8125rem, colore `var(--text-muted)` #5a6a7a, separatore `·` su desktop / stack verticale su mobile.

**ELEMENTO VISIVO (lato destro desktop / sotto copy su mobile):**
Foto reale di Angelo al lavoro (se disponibile) — formato verticale, bordi arrotondati 12px, leggera ombra `box-shadow: 0 8px 32px rgba(0,0,0,0.10)`. In assenza di foto: mockup tracciato ECG stilizzato in `var(--accent2)` su sfondo bianco, con overlay testo "ECG da €25".

*Nessun carosello, nessuna animazione complessa. L'immagine è statica. Il movimento distrae.*

### Scala Tipografica

```css
/* Display / Hero H1 */
h1 {
  font-family: var(--font-display);
  font-size: clamp(1.875rem, 4vw, 2.75rem);  /* 30px → 44px */
  font-weight: 800;
  line-height: 1.15;
  color: var(--text-primary);
  letter-spacing: -0.02em;
}

/* Section Title H2 */
h2 {
  font-family: var(--font-display);
  font-size: clamp(1.375rem, 2.5vw, 1.875rem);  /* 22px → 30px */
  font-weight: 700;
  line-height: 1.25;
  color: var(--text-primary);
}

/* Card Title H3 */
h3 {
  font-size: clamp(1.0625rem, 1.5vw, 1.25rem);  /* 17px → 20px */
  font-weight: 700;
  line-height: 1.3;
  color: var(--text-primary);
}

/* Body text */
body, p {
  font-family: var(--font-body);
  font-size: clamp(1rem, 1.2vw, 1.0625rem);  /* 16px → 17px */
  line-height: 1.65;
  color: var(--text-secondary);
}

/* Caption / note */
.caption {
  font-size: 0.8125rem;  /* 13px */
  color: var(--text-muted);
  line-height: 1.5;
}
```

*Motivazione scala: font-size minimo 16px su tutti i testi (WCAG AA, critico per anziani). Il `clamp()` garantisce leggibilità senza media query aggiuntive. Font-weight 800 per H1 perché su sfondo chiaro le headline leggere sembrano instabili — l'anziano percepisce autorevolezza nel peso del testo.*
